# Codex Slot Ping v0.2.0

Codex Slot Ping v0.2.0 makes automatic scheduling status easier to understand and control.

## What changed

- **Eligibility explanations:** Main and Settings explain why an automatic attempt is or is not planned.
- **Consistent status:** Main, Settings, and Tray use the App-owned Read Model; the Tray menu includes a compact scheduler status summary.
- **Pause / Resume:** Pause stops automatic scheduling while keeping automation enabled. Resume calculates a fresh plan.
- **Manual Test Now:** Test Now remains an explicit user-initiated path while automatic scheduling is paused. A request can count toward Codex usage.
- **Clear timing language:** “Next planned attempt” means a local planned attempt time, not a quota reset time.

## Known limitations

- Codex usage initiated outside this app is not observable.
- There is no complete execution history.
- If saving Pause fails, temporary protection applies only to the current running App/Windows session and does not survive an App or Windows restart.
- Codex Slot Ping is not a Task Runtime or Provider framework.
