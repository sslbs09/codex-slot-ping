# Codex Slot Ping v0.3.0 — release notes draft

**Status: RC validation draft. This version has not been released.**

## Update delivery

- Checks GitHub stable Releases for a compatible update and lets the user choose when to download and install it.
- Verifies the downloaded ZIP against its SHA-256 sidecar and validates the package manifest and executable versions before staging.
- Stages the package separately, then hands installation to the independent Updater after the App exits and active Runner work drains.
- Keeps the current installation available for rollback until the new App reports a matching startup acknowledgement. Interrupted or failed transactions are handled through recovery.
- SHA-256 detects corruption or mismatched assets. It does not establish publisher authenticity.

## Upgrade from v0.2.0

The first updater-enabled version requires one manual bootstrap upgrade from v0.2.0. Keep the installation at its existing path so the Windows Task Scheduler Runner path stays valid. Pause scheduling, confirm that no Test Now or Runner process is active, exit the App fully, retain a backup of the old installation, and extract the v0.3.0 package into the same path. Then verify that the App starts, LocalAppData configuration and state remain intact, Pause remains active, and Scheduler health is normal before resuming.

From v0.3.0 onward, later compatible stable versions can use the built-in update path.

## Not included

Updates are user-approved; they are not silent or forced. The updater does not elevate privileges automatically.
